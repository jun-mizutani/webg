サンプル: mmodeler

概要
- mmodeler は、スマートフォンやタブレットのタッチ操作に最適化した Blender 風の 3D modeler です
- カメラ操作、選択、移動、回転、押し出し、ループカット、細分化、プリミティブ追加、ファイルの保存／読込を、タップ、ダブルタップ、長押し、ドラッグで操作できます

mobile 操作体系
- 1 本指ドラッグ: 通常時は camera orbit。box select 準備中は矩形 preview
- 2 本指ドラッグ: camera pan
- pinch: camera zoom
- 短い tap: Object Mode では object、Edit Mode では現在 tool に応じて vertex または face を選択。Add Vertex tool では tap 位置へ頂点を追加
- 画面左上の ↑: Shift 相当の追加選択 toggle。active の間は tap 選択を続けられ、選択済みの vertex / face をもう一度 tap すると選択解除
- double tap on geometry: 現在の選択状態を維持したまま 4x4 の command palette を開く。double tap だけでは pointer 下の geometry を自動選択しません
- double tap on empty with geometry: box select を準備し、次のドラッグで矩形 preview、tap で複数選択を確定
- double tap on empty scene: command palette を開く。頂点が 1 つもない状態では囲む対象がないため、Load や primitive 追加を呼び出せるようにします
- long press on hit: Object / Edit Mode を切り替え
- long press on empty: 状態表示のみ。camera や選択状態は変更しません

command palette の基本
- command palette は double tap で表示される 4x4 の grid menu です。Next で 4 枚の page を循環します
- palette を開くとき、保留中の single tap 選択は破棄します。これにより、palette 表示後に 1 回目 tap の選択処理が遅れて走り、操作対象が変わることを防ぎます
- 選択中や toggle 中の command は控えめな active 色で示します。選択が前提の command は、対象がない場合は無効になります
- command palette は double tap した点を覆い隠さないよう、tap 位置が画面中心より右上なら右上、左下なら左下のように、画面中心から見た象限方向へずらして表示します。その方向に余地がない場合は対角側を試し、最終的には画面内へ収まる位置へ寄せます
- Edit Mode へ入った直後の選択 tool は Face です。command palette でも Face が active 表示になり、必要な場合だけ Vert へ切り替えます
- X mirror が ON のときは、command palette の M / mirror ボタンが控えめな active 表示になります。OFF のときは通常色に戻ります
- 視点切り替えの X/-X/Y/-Y/Z/-Z は view dock として常時表示します。縦長画面では画面上部、横長画面では右端へ配置し、command palette を開かなくても 6 方向の view を直接選べるようにします
- 常時見える UI は canvas、status、view dock を中心にし、command は double tap 時だけ表示する grid command menu へ絞ります。詳細な debug 情報は status や diagnostics に残しつつ、普段の mobile 画面では重ね表示しません

主な編集 command
- G/R/S/E/GG は、選択後に 1 本指ドラッグで preview します。pointerup は確定ではなくドラッグ segment の終了です。目的の位置になったら短い tap で確定します
- X/Y/Z/N は transform command を選ぶ前に押す軸制限 option です。N は Edit Mode で選択 face の平均法線方向、または vertex 選択時に選択 vertex 周辺 face の平均法線方向に制限します。もう一度押すと Free に戻ります
- GG は、選択 vertex が 2 つの隣接 vertex に挟まれた中点である場合、その元 edge の直線上で slide します。任意の接続 edge 上を動く command ではありません
- Cut は Edit Mode で四角 face を選択して使います。選択 face を開始点に隣接する四角面へ cut を伝播し、各四角面を 2 枚の四角面へ分割します。単独 face では緑の preview 線で方向を選び、tap で確定します。X mirror が ON の場合は、source 側で決まった cut 方向を mirror face 上の対応 edge へ写し、左右を同じ command で分割します
- Chain は、選択 vertex から隣接 edge の方向を preview し、quad 面だけでつながる vertex chain を tap で確定選択します。UV 球の緯線のような曲線 loop もたどりますが、立方体の 90 度角や三角面、五角面に当たると停止します
- Loop は Select Loop です。loop cut で作成された中点 vertex から、左右の polygon 内で対辺側にある中点 vertex へ選択を広げます。Cut の後に Loop で中点列を選び、そのまま GG で形を調整できます
- Add は Edit Mode で 3 個または 4 個の頂点を選択しているときは face 作成、それ以外では Add Vertex tool へ切り替えます
- Subd は quad-only mesh を 1 段階 subdivision します。三角面や非 quad を含む mesh では実行しません
- Catm は Catmull-Clark subdivision です。non-manifold edge や分岐した boundary など、smoothing の解釈が曖昧な形状では実行しません
- 選択済み vertex は赤い marker で表示され、両端の vertex が選択済みの edge も赤く表示されます

入力判断フロー
- mmodeler の mobile profile では、command 呼び出しを double tap に集約します。canvas 上の 1 本指ドラッグは通常時は camera orbit として扱い、速く横へ動かしても command palette や page 切り替えにはしません
- 短い tap は single tap か double tap かを判断するため、すぐには選択へ確定しません。pointerup 後に短い猶予を置き、その間に 2 回目の tap、long press、palette 表示、box select 開始が来なかった場合だけ single tap 選択として実行します。これにより double tap で palette を開く前に、1 回目の tap が選択解除や active object 変更を起こすことを防ぎます
- single tap として確定した場合は、Object Mode では object、Edit Mode では現在 tool に応じて vertex / face を選びます。Add Vertex tool では tap 位置へ頂点を追加します。移動距離が大きい操作は tap ではなくドラッグとして扱い、通常時は camera、box select 準備中は矩形選択に回します
- 画面左上の ↑ が active の間、single tap 選択は PC の Shift キーと同じ追加選択として扱います。追加選択中に選択済み vertex / face を tap すると、その要素だけを選択から外します
- geometry 上で double tap した場合は command palette を開きます。このとき pointer 下の geometry は自動選択せず、既存選択があればその選択状態を維持します。未選択状態でも command palette を開けるため、Load、New、primitive 追加など選択なしで意味を持つ command を呼び出せます
- command palette を開くときは、保留中の single tap 選択を破棄します。これにより、palette 表示後に 1 回目 tap の選択処理が遅れて走り、操作対象が変わることを防ぎます
- 図形が存在する状態で empty 上を double tap した場合は boxSelectArmed になり、次のドラッグを矩形選択 preview として扱います。この状態では camera orbit を止めます。ドラッグ後の pointerup では矩形を表示したまま確定待ちに入り、tap で選択を確定して camera orbit を再開します。確定前に範囲が違うと感じた場合は、もう一度ドラッグして矩形を作り直せます。boxSelectArmed や preview 確定待ちの状態で再度 double tap すると矩形選択を解除します。頂点が 1 つもない状態の empty double tap は boxSelectArmed にせず、command palette を開きます
- canvas 上で long press した場合は、対象があれば Object / Edit mode を切り替えます。空き領域では状態表示だけを行い、camera や選択状態は変更しません。long press が成立した場合も保留中の single tap 選択は破棄します
- transform 中は transformController が pointer を優先して受け取ります。タッチ pointer では pointermove で preview し、pointerup は segment 終了として次のドラッグの基準を更新します。確定は短い tap で行うため、スマホでも G/R/S/E/GG 後に ドラッグ、ドラッグ、tap のように複数回に分けて形状を動かせます
- DebugDock の mobileLastGesture には、double tap、long press、box select、transform などの入力状態が記録されます。camera 操作と command 実行を分けているため、canvas ドラッグが command として誤判定されないことを diagnostics から確認できます

操作説明
- tap on canvas: double tap 判定時間の後、現在 mode / tool に応じて object / vertex / face を選択、または Add Vertex tool なら頂点を追加
- tap ↑ button: Shift 相当の追加選択 mode を ON / OFF
- double tap on geometry: 現在の選択状態を維持したまま grid command menu を開く
- double tap on empty with geometry: box select を準備し、次のドラッグで矩形 preview、tap で複数選択を確定。準備中または preview 中の double tap は cancel
- double tap on empty scene: command palette を開く
- long press on hit: Object / Edit mode を切り替え
- long press on empty: 状態表示だけを行い、camera や選択状態は変更しない
- ドラッグ after G/R/S/E/GG: command palette を閉じた canvas 上で transform preview。pointerup は segment 終了
- 2 本指回転: view roll。camera target や距離は保ったまま、画面中心を軸に視野そのものを回転します。pinch zoom と 2 本指 pan は同じ gesture の距離変化と中心移動から同時に反映されます
- tap X / Y / Z on command palette: transform command を選ぶ前に軸制限 option を指定
- tap during transform: transform を確定
- tap during loop cut preview: 現在表示中の preview 方向で loop cut を確定
- tap view dock X/-X/Y/-Y/Z/-Z: 6 方向の view を直接選ぶ。2 本指回転で傾けた view roll も 0 に戻ります
- 1 本指ドラッグ on canvas: 通常時は orbit camera。box select 準備中は矩形 preview
- 2 本指ドラッグ on canvas: pan camera
- pinch on canvas: zoom camera

1st command palette の意味
- 1 枚目は基本編集 command と transform 軸制限 option を集めています。表示上の行は G / E / Vert / X、R / GG / Face / Y、S / Cut / Undo / Z、Next / Chain / Redo / N の順です
- G: Move。選択中の object、face、vertex を移動する transform command です。押したあと canvas を 1 本指でドラッグすると preview し、短い tap で確定します
- E: Extrude。Edit Mode で選択中の face または vertex を押し出します。押し出し後の移動量は canvas drag で調整し、tap で確定します
- Vert: Vertex Select。Edit Mode の選択対象を vertex に切り替えます。Object Mode から使った場合は active object を編集対象にする流れで vertex 編集へ入ります
- X: X Axis。次に実行する G / R / S / E / GG の操作方向を world X 軸に制限します。もう一度押すと Free に戻ります
- R: Rotate。選択中の object、face、vertex を回転する transform command です。drag で角度を preview し、tap で確定します
- GG: Edge Slide。選択 vertex が 2 つの隣接 vertex に挟まれた中点である場合、その元 edge の直線上で slide します。loop cut 後の中点調整に使います
- Face: Face Select。Edit Mode の選択対象を face に切り替えます。面を選択して Cut、E、Del などの編集 command を実行できます
- Y: Y Axis。次に実行する G / R / S / E / GG の操作方向を world Y 軸に制限します。もう一度押すと Free に戻ります
- S: Scale。選択中の object、face、vertex を拡大縮小する transform command です。drag で倍率を preview し、tap で確定します
- Cut: Loop Cut。Edit Mode で選択した quad face を分割します。単一 face 選択時は preview 線を見ながら方向を選び、tap で確定します
- Undo: 直前の編集操作を 1 つ戻します。transform、選択を伴う編集、primitive 追加などを元に戻すための command です
- Z: Z Axis。次に実行する G / R / S / E / GG の操作方向を world Z 軸に制限します。もう一度押すと Free に戻ります
- Next: 2nd command palette へ切り替えます。command を実行せず、次のページを表示するだけです
- Chain: Chain Select。選択 vertex から隣接 edge の方向を preview し、quad 面だけでつながる vertex chain を tap で確定選択します。立方体の 90 度角では停止します
- Redo: Undo で戻した編集操作を 1 つやり直します。戻しすぎた操作を再適用するときに使います
- N: Normal Axis。Edit Mode で選択 face の平均法線方向、または vertex 選択時に選択 vertex 周辺 face の平均法線方向へ transform を制限します。もう一度押すと Free に戻ります
- 視点切り替えは常時表示の view dock から行う

view dock の意味
- X: X 方向から見る側面 view に切り替えます
- -X: 反対側の X 方向から見る側面 view に切り替えます
- Y: Y 方向から見る上面 view に切り替えます
- -Y: 反対側の Y 方向から見る上面 view に切り替えます
- Z: Z 方向から見る正面 view に切り替えます
- -Z: 反対側の Z 方向から見る正面 view に切り替えます
- view dock button を押すと、camera target と距離は維持したまま、view roll は 0 に戻ります

2nd command palette の意味
- 2 枚目は選択、細分化、表示切り替えを集めています。表示上の行は Catm / A / Add / Pr、Subd / Inv / Del / Wire、M / Half / - / Smth、Next / Loop / - / Lens の順です
- Catm: Catmull-Clark 細分化。active mesh 全体を滑らかさを加えながら細分化します。角を丸めた subdivision surface 風の形状にしたいときに使います
- A: Select All。Object Mode では全 object、Edit Mode では現在の選択モードに応じて全 vertex または全 face を選択します
- Add: Add Vertex / Make Face。3 個または 4 個の vertex を選択中なら face を作成します。それ以外では tap 位置へ vertex を追加する tool に切り替えます
- Pr: Projection。透視投影と orthographic view を切り替えます。形状確認では透視、正確な位置合わせでは orthographic が向いています
- Subd: Subdivide。quad-only mesh を 1 段階細分化します。面構造を保ったまま polygon 密度を増やしたいときに使います
- Inv: Invert Selection。現在の選択状態を反転します。選ばれている要素を外し、選ばれていない要素を選択します
- Del: Delete。Object Mode では選択 object、Edit Mode では選択 vertex または face を削除します
- Wire: Wireframe。Object / Edit Mode の mesh wireframe 表示を切り替えます。Edit Mode で ON の間は、wireframe として見えている裏側の vertex も選択対象にします
- M: X Mirror。X=0 を基準にした mirror 編集を切り替えます。loop cut など一部の編集では反対側にも対応する処理を反映します
- Half: Select X<0。X 座標が 0 より小さい側の要素を選択します。片側を削除したり mirror 編集の準備をしたりするときに使います
- Smth: 滑らかな陰影表示。共有頂点構造を変えず、SmoothShader の flat_shading を切り替えて陰影だけを滑らかに表示します。形状そのものは変更しません
- Lens: Camera Lens。camera focal length preset を切り替えます。画角を変えて、広角寄りまたは望遠寄りの見え方を確認できます
- Next: 3rd command palette へ切り替えます。command を実行せず、次のページを表示するだけです
- Loop: Select Loop。loop cut で作成された中点 vertex から、左右の polygon 内で対辺側にある中点 vertex へ選択を広げます。元 edge の colinear 方向ではなく、cut line の方向をたどります

3rd command palette の意味
- 3 枚目は file 操作、scene 操作、object 操作を集めています。表示上の行は Load / O / - / Cood、Json / Shot / - / Info、Glb / Join / - / -、Next / - / - / New の順です
- Load: ファイル読込。ローカル file picker を開き、対応する model file や保存済み ModelAsset JSON を読み込みます
- O: Origin。選択中 object の origin を world origin へ戻します。object の local geometry は保ったまま、object の基準点を整えます
- Cood: 座標表示 overlay。Edit Mode で選択中の vertex 座標を表示し、単一 vertex 選択時は X / Y / Z を直接入力して更新できます
- Info: active object のバウンディングボックスのサイズ、頂点数、ポリゴン数、原点を一時 overlay に表示し、tap で閉じます
- Json: JSON 保存。現在の scene を gzip 圧縮済み ModelAsset JSON (.json.gz) として保存します。mmodeler で再編集しやすい保存形式です
- Shot: 画像保存。現在の canvas 表示を画像として保存します。作業途中の見た目確認や共有用に使います
- Glb: GLB 保存。現在の scene を GLB file として保存します。ほかの 3D tool や viewer へ持ち出すための export です
- Join: Object Mode で選択中の 2 個以上の object を 1 object へ統合
- New: 新規 scene。現在の scene を破棄して、新しい空の scene を開始します
- Next: 4th command palette へ切り替えます。command を実行せず、次のページを表示するだけです

4th command palette の意味
- 4 枚目は primitive 追加と primitive の分割数を集めています。表示上の行は Cube / Torus / Ball / DCone、Cyl / Cone / Plane / -、3 / 4 / 8 / 12、Next / 16 / 24 / 32 の順です
- Cube: Cube。local origin が中心にある cube object を scene に追加します。追加後は通常の object として移動、編集、保存できます
- Torus: Torus。local origin が中心にある torus object を scene に追加します。現在選んでいる primitive 分割数が ring / tube の密度に反映されます
- Ball: Sphere。local origin が中心にある sphere object を scene に追加します。現在選んでいる primitive 分割数が経度方向と緯度方向の密度に反映されます
- DCone: Double Cone。上下に apex を持つ double cone object を scene に追加します。中心の ring が local origin の高さに置かれます
- Cyl: Cylinder。local origin が中心にある cylinder object を scene に追加します。現在選んでいる primitive 分割数が円周方向の密度に反映されます
- Cone: Cone。local origin が中心にある cone object を scene に追加します。底面と apex の中間が object origin になります
- Plane: Plane。local origin が中心にある XZ 平面の plane object を scene に追加します。床面や押し出し元の下地として使えます
- 3 / 4 / 8 / 12 / 16 / 24 / 32: Primitive Segments。Ball、Torus、Cyl、Cone、DCone の分割数を選びます。どれか 1 つが active 表示になり、初期値は 12 です
- Next: 1st command palette へ戻ります。command を実行せず、最初のページを表示します

選択状態の方針
- mobile では geometry 上の double tap を command palette 表示に使い、double tap だけで geometry を選択しません。これにより、未選択でも使える command を呼び出すための状態を保てます
- empty 上の double tap は矩形選択の開始に使います。geometry 上で command、empty 上で範囲選択という役割分担にすることで、camera ドラッグとの衝突を避けます
- 矩形選択はドラッグ終了時点では確定せず、矩形を表示したまま確認できます。tap で確定するまで再ドラッグで修正できるため、スマホで指に隠れていた終点を確認してから選択を変えられます
- 複数選択は A select all、I invert selection、H select X<0 などの command を中心に扱います。face / vertex の混在選択は desktop 版と同じく mode / tool ごとに分け、同時編集対象を曖昧にしません
- 画面左上の ↑ toggle は、細かい vertex / face を連続して選ぶための mobile 用 Shift です。状態は status とボタンの active 表示で確認できます

このサンプルで使う webg 機能
- WebgApp: embedded canvas、Screen / Shader / Space / Input / Message の初期化
- EyeRig: 1 本指 orbit、2 本指 pan、pinch zoom を含むタッチ camera
- Touch.attachSurface(): double tap、long press を gesture として検出。mmodeler では command palette 表示と mode 切り替えに使います
- ModelAsset: 編集結果の保存形式、読み込み済み asset の mesh 取り出し、gzip 圧縮済み JSON download
- WebgApp.loadModel(): glTF / GLB / Collada を ModelAsset へ正規化する入口
- Overlay2DRenderer: Edit Mode の頂点 marker overlay
- EdgeWireframeOverlayRenderer: Edit Mode の edge overlay
- Space.raycast(): object / face pick

Blender との ModelAsset JSON 受け渡し
- samples/mmodeler/blender_modelasset_io.py は、mmodeler の .json / .json.gz 保存データを Blender と受け渡しするための Blender アドオンです
- Blender の Edit > Preferences > Add-ons > Install... から samples/mmodeler/blender_modelasset_io.py を選び、Webg ModelAsset JSON I/O を有効化します
- 有効化後は File > Import > Webg ModelAsset JSON (.json) と File > Export > Webg ModelAsset JSON (.json) が追加されます。対象形式は .json と .json.gz です
- mmodeler から Blender へ渡す場合は、mmodeler の Json で ma_YYYYMMDD_HHMMSS.json.gz 形式のファイルを保存し、Blender 側で Import します
- Blender から mmodeler へ戻す場合は、Blender 側で mesh object を選択して Export し、mmodeler の Load で書き出した .json または .json.gz を読み込みます
- Export オプションの Export as .json.gz を ON にすると gzip 圧縮済み .json.gz、OFF にすると通常の .json を書き出します。保存名に .json や .json.gz が既に付いていても、二重拡張子にならないよう正規化します
- Import / Export では既定で Blender の Z-up と ModelAsset の Y-up を相互変換します。軸変換を行いたくない検証では、Import / Export オプションの axis conversion を OFF にします
- このアドオンは mesh geometry、material の基本色、polygonLoops を中心に扱います。複雑な rig、animation、一般的な 3D ツール連携を優先する場合は GLB / glTF 経路を使います

読み込み時の段階表示
- .json.gz を読み込むと、status/message に loading <file>: decompressing、loading <file>: parsing、loading <file>: importing の順で表示します。iPhone Safari などで固まる場合に、gzip 展開、JSON parse、editor への取り込みのどこで止まったかを見分けるための表示です
- 各段階表示の直後に 1 frame 待ってから重い処理へ入ります。これにより、JSON parse などの同期処理で browser が固まった場合でも、直前の段階名が画面へ反映されやすくなります
- .json は gzip 展開がないため parsing から始まり、その後 importing へ進みます。glTF / GLB / Collada は loader の stage 表示を使い、ModelAsset 化後に importing へ進みます

確認ポイント
- 起動直後に full-screen canvas が広く見え、canvas 外 panel や上部 HUD がないことを確認します
- tap で object / vertex / face を選択できることを確認します
- 画面左上の ↑ を ON にして、vertex / face を連続 tap で追加選択でき、選択済み要素をもう一度 tap すると外れることを確認します
- selection 上の double tap で command palette が開き、Next で 1st / 2nd / 3rd / 4th の 4 枚が循環することを確認します
- active 状態の command は控えめな色、Next は赤系の色で表示されることを確認します
- Edit Mode で隣り合う四角 face を選択し、Cut で選択範囲外の隣接四角面にもカットが伝播し、中点 vertex が共有されることを確認します
- Edit Mode で四角 face を 1 枚だけ選択し、Cut 後にドラッグで pointer を face の各辺へ近づけると緑の preview 線が切り替わり、短い tap で表示中の方向の loop cut が確定することを確認します。preview 中に長押しや mode 切り替え操作をしても Object Mode へ移らず、確定または Escape cancel を求める message が出ることを確認します
- X mirror が ON の状態で片側の四角 face を Cut すると、反対側の mirror face も対応する方向で loop cut されることを確認します
- 任意の分岐 vertex や UV 球の緯線上の vertex を Vertex Select で選択し、1st palette の Chain で preview 線を選んで tap すると、quad 面だけでつながる vertex chain が選択され、三角面や五角面では停止することを確認します
- loop cut で作成された中点 vertex を Vertex Select で選択し、2nd palette の Loop で左右の polygon の対辺中点へ選択が広がることを確認します
- Loop で選択された中点列の edge が赤く表示されることを確認します
- Edit Mode で 3 個または 4 個の頂点を選択したとき、Add の tap で面を作成できることを確認します
- 2nd palette の Wire で Object / Edit Mode の mesh wireframe 表示が切り替わり、Edit Mode では見えている裏側の vertex も選択できることを確認します
- 2nd palette の Smth で mesh の smooth shading 表示が切り替わることを確認します
- 2nd palette の Pr で透視投影と orthogonal view が切り替わることを確認します
- 2nd palette の Subd と Catm が対象 mesh の条件を満たすときだけ実行されることを確認します
- 1st palette の GG を選んだあと、ドラッグで選択 vertex が元 edge の直線上を slide し、複数回ドラッグしたあと tap で確定できることを確認します
- 3rd palette の Cood で coordinate overlay が開き、単一 vertex 選択時は X / Y / Z を入力して Apply で座標を更新できることを確認します
- Object Mode で複数 object を選択し、3rd palette の Join で 1 object へ統合できることを確認します
- 4th palette の Cube / Torus / Ball / DCone / Cyl / Cone / Plane で既存 object を残したまま primitive object を追加できることを確認します
- 4th palette の分割数ボタンを押すと active 表示が切り替わり、その後に追加する Ball / Torus / Cyl / Cone / DCone の分割数へ反映されることを確認します
- G/R/S/E を選んだあと command palette が閉じ、1 本指ドラッグで preview が動き、pointerup では状態が保持され、短い tap で確定できることを確認します
- 1st palette の X/Y/Z を押してから G/R/S/E を選ぶと、選んだ world 軸方向だけへ transform preview が制限されることを確認します
- 未選択状態で polygon 上を double tap しても、その polygon / face / vertex が自動選択されず、未選択のまま command palette が開くことを確認します
- canvas 上の 1 本指ドラッグは速く動かしても camera orbit として動作し、command が誤実行されないことを確認します
- 3rd palette から読込、保存、画像保存、新規 scene などが実行できることを確認します
- X mirror が ON のとき、palette 上の M / mirror ボタンが active 色に変わることを確認します
- 図形が存在する状態で empty 上を double tap したあとドラッグすると、camera が回らず box select preview が表示され、tap で確定するまで矩形が残ることを確認します
- boxSelectArmed または box select preview 表示中にもう一度 double tap すると、矩形選択が解除され camera orbit が戻ることを確認します
- 全 object を削除して頂点が 1 つもない状態では、empty double tap で command palette が開き、primitive 追加や Load を選べることを確認します
- 1 本指ドラッグで orbit、2 本指ドラッグで pan、pinch zoom が scene 上で動くことを確認します

補足
- このサンプルは mobile profile の構成であり、スマホやタブレット上での command palette 操作を優先しています
- 編集データ、pick、transform、保存形式は同じ画面内で一貫して扱い、mobile 専用に別仕様の geometry を持たないようにしています
