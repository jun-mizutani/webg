# Studio Small 01 HDR and generated cache

`studio_small_01_1k.hdr` is the 1K Radiance HDR from Poly Haven's [Studio Small 01](https://polyhaven.com/a/studio_small_01). The author is Greg Zaal and the license is CC0. The source SHA-256 is `a2d308672f077b0872686a439d76dc3ace91274380ae2e5f02c653c3ccbc8407`, its size is 1,701,440 bytes, its decoded dimensions are 1024×512, and its maximum radiance is 606.

`studio_small_01_1k_standard.webgpbr` is a webg cache generated after conversion from Radiance standard primaries to linear sRGB, using the `standard` preset and `webg-split-sum-ggx-environment-mis-linear-srgb-v3`. Its SHA-256 is `7a5b67be27efcf768b5e5b027c0395d9eed0a23e3184b5d89c2e48c948213f2d` and its size is 4,627,199 bytes. `studio_small_01_1k_standard.json` records color conversion, complete settings, memory, and timings; `studio_small_01_1k_standard_quality.json` records comparison with a 2048-sample CPU reference.

Normalized RMSE between 512 samples and the 2048-sample reference is 0.010504 for irradiance, 0.00003517 for specular mip 0, and 0.010160 for the coarsest mip 8. The BRDF LUT value is 0.00161427. This finalized asset uses the same linear-sRGB luminance coefficients for importance sampling as the converted working-space pixels.
