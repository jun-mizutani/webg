Compare the same 200-box scenario with the CPU core and Compute core.

Overview

This sample compares a 200-box falling scenario in CPU and Compute versions. The CPU page uses the normal PhysicsSpace API and its CPU Box contact implementation, while the Compute page uses the core ComputePhysicsSpace. Both start with the same seed, initial transforms, angular velocities, gravity, five Plane boundaries, fixed timestep, solver iterations, and sleep settings.

How to Run

  • CPU falling_box_cpu.html: registers PhysicsNode and PlaneCollider objects with the normal PhysicsSpace
  • Compute falling_box_compute.html: uses the GPU BodyState and WGSL solver of ComputePhysicsSpace

The Help Panel starts collapsed. Press H to inspect frame interval, GPU Render and JavaScript load, active bodies, sleeping bodies, and fixed-step count.

Shared Scenario

The initial conditions are defined in fallingBoxScenario.js. The 200 bodies are arranged in layers with placement jitter reproduced from seed 20260822. Each body is a Box, and five Planes represent the floor and four walls. Gravity is -4.9 m/s², the fixed timestep is 1/120 s, and the solver uses 14 iterations.

The CPU page converts the shared descriptors into PhysicsNode and BoxCollider objects, then registers the five Planes as static PhysicsNode objects in PhysicsSpace. PhysicsSpace converts those registered Planes into solver inputs and resolves the Box/Plane contacts in one CPU path. The visible floor board is a separate normal Node, so the floor is not solved twice. The Compute page converts the same descriptors into GPU BodyState records for ComputePhysicsSpace.

What to Check

Run both pages with the same conditions and confirm that the 200 bodies fall, contact the boundary Planes, and move toward a settled state. The goal is to inspect the complete fall, contact, and sleep process and the CPU Node-rendering versus Compute GPU-state-rendering difference rather than bit-for-bit numerical equality.

Controls

  • P or Space: pause / resume
  • R: reload the page and reset the initial conditions
  • H: expand / collapse the Help Panel
  • Drag: orbit the camera; mouse wheel: zoom
