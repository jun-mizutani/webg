webg samples

65本の公開サンプルを、bookの章に対応する分野別に整理しています。各分野の中はフォルダ名のアルファベット順です。概要で目的を確認し、実行ページで動作を試してから、詳細説明へ進めます。

一覧と詳細説明の使い分け

初めて開発する場合は、実行例から始める開発案内で、目的に合う出発点と、次に追加する機能の例を選べます。人とAIが同じコードと確認ポイントを使うための案内です。

実行はサンプルアプリケーションを開きます。詳細（日本語）はREADME.mdと同内容をUTF-8のHTMLにしたページです。生のMarkdownをブラウザーへ直接表示しないため、Webサーバーの文字コード判定による文字化けを避けられます。原文が必要な場合はREADME.mdを保存を利用してください。

開発用の目視確認はunittest一覧、book本文の実行例はbook examples一覧、sample・unittest・headless testの違いはsamples/README.mdにあります。English guide

YAMLによるモデルとシーンの扱いは、ModelYAML単体の読込・配置、SceneYAML＋ModelYAMLによるPBR表示・物理の順に試せます。画面で配置や材質を編集する場合はSceneYAMLエディタを利用してください。

開発時にコアmoduleを強制再importする場合は、cache_clear_webg（webg core cache clear）を使えます。全webg moduleを一意な?v=...付きURLでimportし、コア自身のimport文は変更しません。

WebgAppを使うサンプルは通常release modeで起動します。F9のあとにMでdebug / release mode、Cで診断情報、Vで診断JSONをコピーできます。
