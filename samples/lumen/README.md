# LUMEN — 光の観測所

LUMENは、webgの描画・計算・音楽を一つの空間で体験する小さなSF展示です。中央では金色の三つのリングが発光する球を囲んで回り、左右の展示台では半透明ガラスと反射の強いアルミニウム球を見比べられます。どちらの展示球も少し大きくし、直径2.3の球体にしました。中央のリングと球は展示空間の基準位置から40%高い位置に浮かび、パルスも同じ高さから広がります。手前のトレイには、Compute物理で動く12個の金属球を置いています。

## 実行と操作

[lumen.html](lumen.html) をWebGPU対応ブラウザで開きます。リポジトリをHTTPで配信している場合は、サンプル一覧からLUMENを選べます。初回はGPUの描画・計算処理と環境光を準備するため、準備画面が表示されます。

ドラッグで視点を回し、ホイールで距離を変えられます。展示は自動で進み、8秒ごとに1536個の強く発光する粒子を放出します。12個の球は高さ5〜6.7から落下し、12秒ごとに開始位置へ戻ります。パルスは赤〜橙赤、常時粒子は左のガラス球から上昇します。球とトレイ底面の反発係数は0.85です。リングは常時回転します。操作ボタンはJazzの再生を切り替える「音楽」だけです。音声は操作後に開始し、全体音量は40%、BGM音量は35%に設定しています。

Canvasはウィンドウに合わせて拡大縮小します。狭い画面では操作ボタンを折り返します。

## 利用するwebgの機能

SceneYAMLに共通材質、基本配置、描画設定、Compute物理、粒子の設定をまとめ、WebgSceneAppで構築します。展示の繰り返し配置はJavaScriptで追加します。

PBRで金属の反射とガラスの透過を表現し、環境光に加えてシアン、琥珀色、紫の点光源をDeferred Lightingへ渡します。方向光のシャドウマップで形を支え、SSRで画面内の物体を反射させ、Bloomで発光部の周囲へ光を広げます。ガラスはTransmissionと屈折率を持つ材質、右の球はmetallic 1、roughness 0.08のアルミニウム材質です。

ComputeParticleEmitterは中央の赤いパルスと左のガラス展示から漂う粒子を更新し、PBRのHDR画像へ加算します。Compute物理はトレイと球の接触、跳ね返り、摩擦、停止を計算します。固定刻みは240Hz、反復回数は12です。GameAudioSynthがJazzを合成するため、音声ファイルのダウンロードは不要です。

## 確認ポイント

視点を回すと金属のハイライトと反射が変化し、ガラス越しの形がゆがみます。自動パルスでは粒子の拡散と減衰、照明の明るさの変化を観察できます。周期的な球の落下では、高い位置からの衝突と強い跳ね返りを確認できます。

SSRとTransmissionは画面に描かれた情報を利用するため、視点や画面端で反射・透過の見え方が変わります。小さな発光線や反射の輪郭には画素単位の段差が見える場合があります。GPU負荷はウィンドウサイズと粒子の同時発生数に応じて変わります。描画解像度はCSSピクセル数に合わせています。

## 実装を読む

scene.yamlが共通設定、exhibition.jsが展示形状と物理球の配置、ObservatoryApp.jsが色付き照明と画面サイズ、main.jsが操作・更新・音声・終了処理を担当します。独自の展示形状はPrimitiveからShapeを作り、Nodeへ登録しています。コアライブラリの変更はありません。

物理計算の対象はトレイの5部品と12個の球です。回転リングやガラスの展示は表示用の形状です。SSAOと被写界深度は無効にして、材質と発光の比較をしやすくしています。エラーは画面へ表示して更新を停止します。
