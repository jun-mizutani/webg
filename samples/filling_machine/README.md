# 回転式カプセル充填機

[English](README.en.md) | 日本語

![機構と工程の観察画面](filling_machine.jpg)

打錠機のアプリ `samples/tablet_machine` と同じ観察操作を備えた、webgのWebGPUアプリです。

操作画面と工程説明は英語で表示します。実行ページは [filling_machine.html](filling_machine.html) です。

リポジトリのルートで `python3 -m http.server 8898` を実行し、
`http://localhost:8898/samples/filling_machine/filling_machine.html` を開いてください。

## 仕組み

12組の受け台が回転盤と一緒に移動します。上側の受け台は赤いキャップ、下側の受け台はクリーム色のボディを保持します。ボディには上側の開口と下側の丸い閉端があり、内部へ淡い青の粉末を入れます。

| 工程 | 観察できる動き |
| --- | --- |
| 供給 | 整列ガイドから空のカプセルを受け台へ入れる |
| 分離 | キャップを保持し、吸引部でボディを下げて分離する |
| 充填 | ボディの受け台を外側へ移動し、計量シリンダとノズルから粉末を入れる |
| 結合 | ボディをキャップの下へ戻し、押上げピンで結合する |
| 排出 | 完成品を持ち上げ、樋へ送り出す |
| 清掃・復帰 | 空の受け台が清掃部を通って供給位置へ戻る |

緑の固定軌道は、受け台の高さと外側への移動を案内するカムの模式表示です。青緑の固定部は分離位置の吸引部と清掃部です。粉末のホッパーには上面の開口と粒の層を設け、充填位置には計量シリンダ、上下するピストン、供給ノズルを表示しています。

排出樋は外側へ10度下ります。排出されたカプセルは樋へ倒れながら移動し、外形と傾斜面から位置を求めて上面に沿わせています。

## 操作

- ドラッグ：視点の回転、ホイール：ズーム
- 一時停止・再生：機械の動作を停止・再開
- 回転速度：初期値3 rpm、0～8 rpmで調整
- 1工程進める・工程ボタン：注目する組を工程の代表位置へ移動して停止
- 観察する組：右側の断面図に表示する受け台を選択。3Dでは金色の輪で示す
- 回転位置：回転盤の位置を直接指定して停止
- カプセルと受け台を断面表示：外側半分を開き、内部の粉末と薄い壁を表示。中央軸と下側テーブルは隠す
- カム軌道を表示：固定軌道を表示
- 自動周回：反時計回りに20秒で一周。視点の鉛直軸と俯角を保ち、機械を停止中も周回する
- 全体・側面・上面：自動周回を止め、所定の観察方向へ変更

## 表示の前提

工程を読み取りやすい模式モデルです。寸法はモデル座標で、粉末量は0～100%の状態として表示します。吸引力、粉末の流動、カプセルの変形とロック溝は、機構を示すアニメーションへ簡略化しています。

回転角に沿って工程を連続的に表しています。実機の割出停止や充填量の制御を表現する場合は、回転盤の時間進行と各工程の駆動を個別に設定する構成へ広げられます。

キャップとボディの開口、丸い閉端、薄い壁は3Dと断面図で同じ形状の定義を使います。PBRの環境反射で金属部品を表示し、カプセルは金属度0の光沢材質、粉末は明るい拡散材質として描き分けています。

## ファイル

- `mechanism.js`：工程と受け台の位置、カプセルの断面、樋上の位置
- `main.js`：部品の生成、PBR描画、工程の更新、画面操作
- `filling_machine.html` / `style.css`：観察画面、断面図、操作部品
