VOID STRIKE — 星間リフト防衛線

VOID STRIKEは、星間リフトから現れる敵編隊を迎撃する3Dシューティングです。プレイヤー機は画面の奥行きへ進みながら、敵機の編隊、赤い追尾弾、環状ゲートの間を飛び抜けます。青白い二門レーザーで敵を撃破し、連続撃破で得点倍率を伸ばし、ブーストで弾幕を抜けます。PBR金属機体、色付き照明、発光ゲート、Bloom、Compute火花をまとめ、操作と攻撃の反応が画面いっぱいに伝わる構成にしました。

実行と操作

void_strike.html をWebGPU対応ブラウザで開き、START RUNを選ぶと出撃します。ウェーブが進むほど敵の移動速度と耐久値が上がり、赤い敵弾も飛んできます。機体の耐久がなくなるまで戦闘が続き、撃破スコアと到達ウェーブが終了画面へ表示されます。

  • W / A / S / D または矢印キー: 機体を上下左右へ移動
  • Space: 左右二門からレーザーを連射
  • Shift: エネルギーを消費して高速移動し、使用中は敵弾を防ぐ
  • P / Esc: 一時停止と再開
  • 画面上の方向キー、FIRE、BOOST: タッチまたはポインター操作
  • SOUND: 175 BPMのBGMとゲーム効果音を開始・停止

Canvasはウィンドウ全体へ広がります。画面上部にはスコア、ウェーブ、機体耐久、連続撃破を表示し、左下のゲージにブーストエネルギーを示します。

利用するwebgの機能

ShooterAppはWebgSceneAppを継承し、PBR描画へシアン、紫、琥珀、赤の点光源を接続します。カメラは宇宙戦場を見渡す固定の遠景に置き、Canvasの大きさをウィンドウ変更へ追従させます。方向光のシャドウマップ、SSR、Bloomで金属機体と発光部を描き、SSAOと被写界深度は止めています。

SceneYAMLは暗い環境光、トーンマッピング、SSR、2系統のComputeParticleEmitterを記述します。撃破と被弾では位置に応じたシアン・赤・琥珀色の火花をGPU上で発生させます。機体、敵、レーザーは共有Shapeの表示instanceとしてpoolへ準備し、ゲーム中は位置、姿勢、表示状態だけを更新します。星空は300個の小さな八面体を一つのmeshへまとめ、環状ゲートと星間グリッドで速度と奥行きを見せます。

衝突・得点・ウェーブ進行はサンプル内の軽量なゲーム更新で扱います。プレイヤー弾と敵機、敵弾とプレイヤー機を3D位置で照合し、敵機の耐久値を減らします。GameAudioSynthはrun_neonの175 BPM譜面と短い合成効果音を再生します。音声はSOUND操作後に開始し、マスター音量42%、BGM音量28%です。

確認ポイント

開始後、青いプレイヤー機と赤い敵機が異なる方向へ移動し、Spaceで二本のレーザーを連射できることを確認します。敵への命中では火花が散り、撃破でスコアと連続撃破が増えます。ウェーブを進めると大型の敵が混ざり、複数発の命中が必要になります。

敵弾への接触で機体耐久が減り、短いシールド点滅の間は耐久を保ちます。Shiftのブーストではゲージが減り、敵弾を抜けた後に徐々に回復します。PAUSE後は戦闘を止めたまま再開でき、画面上の方向キーとFIRE・BOOSTでも同じ操作を確認できます。

実装を読む

scene.yamlがPBR、SSR、粒子設定、space_scene.jsが星空・ゲート・機体・弾の生成と再利用pool、ShooterApp.jsが照明・カメラ・Canvasサイズ、main.jsが操作・衝突・ウェーブ・得点・HUD・音声を担当します。シーン固有のコードはこのフォルダ内にまとめています。
