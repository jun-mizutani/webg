compute_particles

標準ComputeParticleEmitterによるGPU粒子

README / English README / 実行

概要

ComputeParticleEmitterを使い、49,152個の粒子をGPUで生成・更新・描画します。利用側はWGSLや粒子bufferのレイアウトを定義せず、発生位置、方向、速度、寿命を標準APIへ渡します。fountainは1件、ringは24件の発生要求で構成し、発光色を線形HDRで加算合成します。

実行方法

HTTPサーバー経由でcompute_particles.htmlを開いてください。WebGPUに対応したブラウザが必要です。

使用しているwebg機能

  • WebgApp: Screen、カメラ、入力、Compute frame、GPU submitを管理
  • ComputeParticleEmitter: 発生要求、storage buffer、uniform、Compute/Render pipeline、billboard描画、寿命更新を管理
  • GpuParticleEmitter: 標準Emitterが継承する低水準GPU resource基盤
  • OverlayPanel: 操作方法、推定生存数、発生要求数、拒否数を表示
  • Screen: Canvasのcolor/depth viewを用意し、同じcommand encoderへComputeとRenderを記録

操作方法

  • Space: 2,048粒の火花を追加発生
  • 1: fountain
  • 2: ring
  • P: 移動・寿命更新の停止／再開
  • H: Help panelの折りたたみ／表示
  • ドラッグ: カメラ回転、Shift + ドラッグ: カメラ移動、ホイール: 拡大縮小

実装の要点

const emitter = new ComputeParticleEmitter(screen.getGPU(), {
  capacity: 49152, preset: "spark", targetFormat: screen.getGPU().format,
  overflow: "replace-oldest",
  simulation: { gravity: [0, -0.70, 0], drag: 0.05 },
  appearance: {
    colors: [[1.0, 0.28, 0.04], [0.04, 0.46, 1.0]],
    intensity: 1.26, size: [0.006, 0.018]
  }
});

発生要求にはposition、direction、spreadAngle、speed、lifetimeを指定します。初期値生成と移動はCompute Shaderが行います。targetFormatはCanvasへ直接描画する形式です。PBRシーンではWebgSceneApp.createComputeParticleEmitter()がHDR中間画像とComputeParticlePassを用意します。

estimatedは最大寿命からCPUが管理する予約数です。通常の描画では粒子位置をGPUからCPUへ戻しません。

確認ポイント

  • 起動直後に49,152個の粒子がfountain状に表示される
  • 2で24方向のring表示へ切り替わる
  • Spaceで追加発生し、容量超過時はreplace-oldestで置換される
  • Pで停止・再開できる
  • Help panelの推定数、要求数、拒否数が操作に応じて変化する
