compute_particles

GPU particles with the standard ComputeParticleEmitter

README / 日本語README / Run

Overview

This sample uses ComputeParticleEmitter to generate, update, and render 49,152 particles on the GPU. Application code supplies emission position, direction, speed, and lifetime without defining custom WGSL or a particle-buffer layout. Fountain uses one request and ring uses 24 requests placed around a circle. HDR colors use additive blending.

How to Run

Open compute_particles.html through an HTTP server in a WebGPU-capable browser.

webg Features Used

  • WebgApp: manages the Screen, camera, input, compute frame, and GPU submission
  • ComputeParticleEmitter: manages emission requests, storage, uniforms, Compute/Render pipelines, billboard rendering, and lifetime updates
  • GpuParticleEmitter: low-level GPU resource base class inherited by the standard emitter
  • OverlayPanel: displays controls, estimated alive count, requests, and rejections
  • Screen: provides Canvas color/depth views and records Compute and Render in one command encoder

Controls

  • Space: emit an additional burst of 2,048 sparks
  • 1: fountain
  • 2: ring
  • P: pause/resume motion and lifetime updates
  • H: collapse/show the Help panel
  • Drag: orbit, Shift + Drag: pan, mouse wheel: zoom

Implementation Details

const emitter = new ComputeParticleEmitter(screen.getGPU(), {
  capacity: 49152, preset: "spark", targetFormat: screen.getGPU().format,
  overflow: "replace-oldest",
  simulation: { gravity: [0, -0.70, 0], drag: 0.05 },
  appearance: {
    colors: [[1.0, 0.28, 0.04], [0.04, 0.46, 1.0]],
    intensity: 1.26, size: [0.006, 0.018]
  }
});

Each emission request specifies position, direction, spreadAngle, speed, and lifetime. The Compute Shader generates initial state and updates motion. targetFormat selects the direct Canvas format. PBR scenes use WebgSceneApp.createComputeParticleEmitter() with an HDR intermediate target and ComputeParticlePass.

estimated is a CPU reservation estimate based on maximum lifetime. Normal rendering keeps particle positions on the GPU.

Checkpoints

  • 49,152 particles appear in a fountain pattern at startup
  • 2 switches to the 24-direction ring pattern
  • Space emits a burst, with replace-oldest handling capacity
  • P pauses and resumes the simulation
  • The Help panel diagnostics respond to controls
