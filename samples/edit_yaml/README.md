# SceneYAML Studio

SceneYAMLをファイルとして読み書きしながら、3Dの配置と形状を編集するサンプルです。WebgSceneAppのPBR表示、SceneDefinitionの検証、SceneYAMLの解析とgzip圧縮を組み合わせています。mmodelerの頂点・面による形状表現とprimitive生成を再利用し、作品データと表示処理を分けています。

## 起動と基本操作

リポジトリをHTTPサーバーで配信し、edit_yaml.htmlをWebGPU対応ブラウザで開きます。localhostまたはHTTPSが必要です。初期作品は床とBoxです。起動時は毎回この初期作品を読み込みます。

左の一覧または3D画面のクリックで物体を選び、右の入力欄で位置、回転角（度）、寸法、色、metallic、roughnessを変更します。ドラッグでカメラを回転し、ホイールで拡大します。Box、Sphere、Capsuleを追加でき、複製、削除、Undo/Redoに対応します。親子関係、scale、詳細設定は選択物体のJSON欄または全体のYAML欄で編集します。共有材質の変更は同じ材質を参照する全物体へ反映されます。複製した物体も材質とmeshを共有します。

## 読込みと保存

「開く」で.yaml、.yml、.yaml.gzを読み込みます。「YAML保存」「gzip保存」で現在の作品をローカルへダウンロードします。ファイルの読み込みと保存はブラウザ内で処理します。未編集の原文はコメントと元の字下げを維持します。フォーム編集を行うと全体を再整形し、コメントは文書先頭へ出典行付きで保持します。データの追加項目は保存します。

YAML欄は「YAMLを反映」、物体JSON欄は「物体設定を反映」で確定します。未反映の入力がある間は他の編集や保存を止めます。「入力を破棄」は両方の入力欄を最後に反映した値へ戻します。不正な値や参照はエラーとして表示し、最後に成功した作品を保持します。新規・読込みで未保存の作品を置き換えるときは確認を表示します。

## メッシュ編集

BoxとSphereをメッシュへ変換できます。物理付き物体は、変換前に物体JSONのphysics.shapeへBox・Sphere・Capsuleの衝突形状を明示してください。変換と頂点編集は表示形状を変更し、衝突形状は指定した値を維持します。変換後は頂点番号を選んでXYZ座標を編集します。画面上の点からも頂点を選べます。点は透過選択なので、奥側の頂点も対象です。選択頂点は橙色、選択面は半透明の橙色で表示します。面番号を選び、法線方向への押し出し、中心点を追加する三角面分割、面削除を実行します。押し出し距離は物体のローカル座標単位です。

メッシュは三角面と四角面を使い、頂点番号は0から始まります。四角面は頂点順に三角形へ分けて表示します。頂点移動で面をねじる場合は先に面分割すると形状を判断しやすくなります。面数が0になる編集、面積0の面、無効な頂点番号を拒否します。上限は1メッシュあたり20000頂点・40000面です。法線はShapeが生成し、material.flatShadingで面ごとの表示を指定できます。形状の編集はBoxとSphereのメッシュ変換、頂点位置、面構成、材質の設定に対応します。

## 保存形式と対応範囲

SceneYAMLの正式形式としてmeshes配列とobjects[].mesh参照を使います。各meshはid、vertices、facesを持ちます。保存した作品は通常のcreateWebgSceneApp({ project: './scene.yaml' })から直接表示できます。mesh物体にphysicsを指定する場合はphysics.shapeにBox・Sphere・Capsuleを明示します。物理には明示したBox・Sphere・Capsuleを使い、表示メッシュには頂点座標と面を入力します。objectSetsはprimitive形状を生成します。

inline objects/materials/physicsに対応し、objectSetsの生成物体はYAMLから編集します。外部SceneAsset、ModelAsset、外部材質ファイルの参照は読込み時に説明付きで拒否します。renderer、animations、独自の追加項目は保存します。表示は編集専用のスタジオ照明を使い、物理・アニメーション・emitter・goalなどの作品固有処理は実行しません。したがって保存作品の実行時の照明や動作は、実行用アプリで確認します。

bodyType、mass、摩擦、反発を編集できます。物理を有効にする作品にはphysics.spaceが必要です。新規作品には240Hz、maxBodies: 128の設定を明示しています。容量を超える場合はYAMLで変更してください。自動で容量や数値を補正しません。

## 実装メモ

main.jsは入力と履歴、scene_document.jsは原文と意味検証、mesh_edit.jsは頂点・面操作、scene_view.jsはPBR表示を担当します。GPU初期化は一度だけ行い、編集時はNodeとShapeを作り直します。メッシュ検証とShape生成はコアのSceneMesh.jsとPrimitiveScene.jsへ統一しています。node samples/edit_yaml/check_document.mjsでGPUを使わないデータ検証を実行できます。開発仕様はdocs/edit_yaml.mdに記載しています。

## 衝突形状の確認と編集

右側の「衝突形状」でBox・Sphere・Capsuleを選び、寸法・半径・半球間の長さとoffset XYZを編集できます。物理なしの物体で形状を選ぶとstaticとして有効になります。種類を変更すると、メニューに表示した初期寸法へ切り替わります。表示メッシュの形状や位置は維持します。dynamicにする場合はbodyTypeを変更し、massを指定します。

選択物体の衝突形状を黄色の透過線で表示します。奥側の辺も表示し、チェックボックスで表示を切り替えられます。offsetは物体local座標で、物体と親の回転に従います。円弧の線は確認用の近似表示です。物理計算には元の半径と長さを渡します。

primitiveでphysics.shapeを省略した場合は表示形状の寸法を使用します。「表示形状を独立した衝突形状へコピー」で現在の形状をphysics.shapeへ保存すると、以降は独立して調整できます。メッシュへ変換する前にもこの操作を使えます。変更はUndo/RedoとYAML保存へ反映されます。物理プレビューの実行は次の拡張段階です。

## 数値入力

数値は入力後にEnterまたはTabで確定します。矢印キーとスピンボタンは0.01刻みで変更します。連続操作中も入力欄のフォーカスを維持します。不正な値はエラーを表示し、直前の有効な値へ戻します。
