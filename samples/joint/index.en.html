joint

日本語 | English

joint is a sample family for comparing the same gravity-driven Joint scenario through CPU and GPU Compute paths. Initial positions, Joint distances, rope dimensions, Capsule orientation, and camera settings are defined in jointScenario.js

joint_cpu_node

Uses webg's CPU PhysicsSpace and ordinary Node drawing to show the CPU Joint solver and standard rendering path

Run joint_cpu_node.html | Implementation notes | 日本語

joint_compute

Updates physics with the ComputePhysicsSpace GPU Joint buffer and WGSL XPBD solver, then renders the ping-pong BodyState directly from a vertex shader

Run joint_compute.html | Implementation notes | 日本語

joint_compute_node

Uses the same GPU physics as joint_compute, then applies an explicit state readback to ordinary Nodes with syncNodesFromPhysics() and renders through Space.draw()

Run joint_compute_node.html | Implementation notes | 日本語

Shared scenario

All three applications use the same pendulum, six hanging ropes, and kinematic Capsule crossing the rope centers. The pendulum DistanceJoint length is calculated by rearranging the small-amplitude relation T=2π√(L/g) as L=|g|(T/(2π))², using gravity 9.80665 m/s² and target period 3 s. Rope links have a 0.06 m radius, a 0.18 m centerline segment, a 0.30 m total length, a 0.305 m center spacing, an apparent gap of about 0.005 m, and a mass of 0.50 kg

The driver Capsule is a gravity-free kinematic body. Its local Y axis is rotated around X by a quaternion so that it points along world Z. Startup moves in the D direction; A/D changes direction and the Capsule stops at either edge. Q selects quasiStatic, which prescribes position at each fixed step and passes zero contact velocity. I selects impact, which passes a prescribed speed of 0.80 m/s to the contact solver

Controls

A: move left　D: move right　Q: quasiStatic　I: impact　P: pause/resume　R: reset　H: toggle Help Panel　Drag: orbit camera　Wheel: zoom camera

Each application follows its own Help Panel startup state. When expanded, it reports physical conditions, body and Joint counts, pendulum target and measured periods, rope speeds, angular speeds, and Joint error. No HUD text is drawn over the scene
