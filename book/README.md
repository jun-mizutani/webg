# webgで3Dアプリケーションを作る

本書は、JavaScriptで3Dアプリケーションを作る読者へ、webgの使い方と描画・物理・音声の仕組みを説明します。まず小さな画面を作り、モデル、入力、アニメーションを追加し、PBRやGPU計算へ表現を広げます。

第I部から第V部までを学ぶ目的で分け、章番号は01〜42で示します。初めて読む場合は基本例を順に試し、作品へ機能を追加する場合は目的の章から読み始められます。


統合版を使う場合は、02章の「統合版を読み込む」から始めてください。
04章には個別モジュール版と同じ例のimportの置き換えがあり、
`付録C_統合版の利用.md`にはサンプル変換の手順があります。
`lib/webg.core.min.js`を利用する場合も、本書のクラスとメソッドの説明を使えます。

## 読み始める場所

作りたいアプリから既存例を選ぶ場合は、[開発の入口と実行例](開発の入口と実行例.md)から始めてください。[ブラウザ版](examples/guide.html)では、目的別の出発点、機能を追加する順序、読むコード、確認ポイントをまとめています。人とAIで同じ案内を使えます。

初めて読む場合は、第I部を順に読みます。画面を表示する最小構成から`WebgApp`、カメラ、マテリアルまでを学べます。

作品として必要な機能を追加するときは、第II部から目的の章を選びます。ModelYAMLで再利用するモデルを用意し、SceneYAMLで作品全体を記述する方法に加え、アニメーション、UI、入力、衝突判定、サウンド、診断情報を扱います。

シェーダーやGPU計算を詳しく知りたい場合は第III部へ進みます。画面効果、物理エンジン、PBR、手続きテクスチャなど、表現を広げたい場合は第IV部を参照します。

座標変換、深度、G-buffer、Shape、スキニング、物理計算の内部処理を調べる場合は第V部を読みます。

PBRの表示から移動・選択・粒子を持つゲームへ進む場合は、
`PBRシーンから小さなゲームへ.md`と`samples/fantasy/`を読みます。
[補足のブラウザ版](examples/fantasy_guide.html)は、読む関数と小さな変更実験を案内します。

水面の反射・屈折と水中の集光は、35章と`samples/water/index.html`で比較します。
ゲームへ追加する例は`samples/fantasy/`です。共通の`WaterBody`、
対象登録、独立ON/OFF、粒子と画面効果への接続、資源の解放を確認します。
