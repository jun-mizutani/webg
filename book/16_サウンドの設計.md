# サウンドの設計

本章では、Web Audio APIを使って効果音とBGMを再生し、場面に合う音量、音色、リズム、残響を組み合わせます。
`GameAudioSynth`を入口にすると、名前付きの効果音と24曲のBGMを選び、作品の操作や進行へ結び付けられます。
独自の旋律や録音素材も同じ音量調整と残響の経路へ接続できるため、作品全体の聞こえ方を一か所で整えられます。

## この章の読み方

### この章を読む前に必要な知識

05章のアプリケーション構成と、JavaScriptのイベント処理を知っていると読みやすくなります。
音声の開始はボタン操作、効果音の再生はゲーム内の出来事、BGMの選択は場面の切り替えと結び付けて考えます。

### 初回に読む範囲

「最小のサウンドアプリ」から始め、音量、効果音、BGMの選択を順に読んでください。
この範囲で、利用者の操作から音声を有効にし、効果音と背景音楽を組み合わせられます。

### 必要になったときに読む範囲

独自の曲を作る場合は「8小節の譜面を登録する」、音色を調整する場合は「音の立ち上がりと余韻」、録音素材を使う場合は「音声ファイルを再生する」を参照してください。

### この章を終えた時点でできること

作品の場面に合わせて音楽と効果音を選び、音量と残響を調整できます。
和音と旋律を譜面として登録し、音声ファイルと組み合わせた音響構成を作れます。

## 三つのクラスで音を組み立てる

webgの音声機能は、単音の生成、音の系統別管理、作品で使うプリセットという三段階で構成されています。
各段階をクラスとして分けることで、アプリケーションは必要な機能を持つ入口を選べます。

`ToneSynth`は、波形から単音を作り、音量の時間変化、左右の定位、ディレイ、リバーブを設定する基盤です。
`AudioSynth`は`ToneSynth`を継承し、SE（Sound Effects：効果音）とBGM（Background Music：背景音楽）の系統、音楽の予約再生、音声ファイルの管理を加えます。
`GameAudioSynth`は`AudioSynth`を継承し、18種類の効果音と24曲のBGM、8小節の譜面を演奏する処理を提供します。

曲データは`webg/GameMusicPresets.js`、効果音の層データは`webg/GameSoundPresets.js`にまとめられています。
譜面の読み取りとゲーム向けの発音は`webg/GameAudioSynth.js`が担当します。
アプリケーション固有の曲は`registerMelody()`で追加できます。
まず`GameAudioSynth`で音を組み込み、音源そのものを作りたい場面で`playTone()`などの単音機能を使うと、段階的に理解できます。

## 最小のサウンドアプリ

音声は、利用者が開始ボタンを押したタイミングで有効にします。
クリック処理の中で`await synth.resume()`を実行し、その完了後に効果音やBGMを開始します。
`resume()`は必要な音声処理を準備し、停止中の`AudioContext`を再開します。

次のHTMLは、`book/examples/`に置いた場合の相対パスで記述しています。
アプリケーションを別の場所へ置く場合は、`import`のパスを配置に合わせて指定してください。

```html
<!doctype html>
<html lang="ja">
<meta charset="UTF-8">
<title>音声の開始と停止</title>
<button id="start">音声を開始</button>
<button id="se" disabled>効果音</button>
<button id="stop" disabled>BGMを停止</button>
<p id="status">開始ボタンを押してください</p>
<script type="module">
import GameAudioSynth from "../../webg/GameAudioSynth.js";

const synth = new GameAudioSynth();
const start = document.getElementById("start");
const se = document.getElementById("se");
const stop = document.getElementById("stop");
const status = document.getElementById("status");

// 利用者の操作から音声を有効にし、曲と音量を設定して再生する
start.addEventListener("click", async () => {
  try {
    await synth.resume();
    synth.setMasterVolume(0.7);
    synth.setSeVolume(0.90);
    synth.setBgmVolume(0.75);
    synth.setMelody("jazz_cafe");
    synth.startBgm();
    se.disabled = false;
    stop.disabled = false;
    status.textContent = synth.getMelodyLabel(synth.melodyName);
  } catch (error) {
    status.textContent = String(error);
    console.error(error);
  }
});

// 操作を受けたことを短い効果音で知らせる
se.addEventListener("click", () => {
  synth.playSe("ui_ok");
});

// BGMの予約処理を止め、音量を滑らかに下げる
stop.addEventListener("click", () => {
  synth.stopBgm(0.2);
  status.textContent = "BGMを停止しました";
});
</script>
</html>
```

`new GameAudioSynth()`は曲や音色の設定を準備します。
音量やエフェクトの設定メソッドにも音声処理を準備する働きがあるため、この例では利用者のクリックから`resume()`を呼んだ後にまとめて設定しています。

`startBgm()`は選択中の曲を開始し、再生中の呼び出しでは現在の演奏を継続します。
`stopBgm()`の後に開始すると、曲の先頭から演奏します。
停止時のディレイやリバーブは、それぞれの経路に設定された余韻として聞こえます。

## 音量と音の出力フロー

複数の音を一つの経路へまとめる部分を「バス」と呼びます。
効果音はSEバス、背景音楽はBGMバスへ送り、各系統の音量と残響を調整してからマスター出力へ合流します。

```text
効果音・SE用の音声素材 → SE音量  → 原音・ディレイ・リバーブ ─┐
                                                          ├→ マスター音量 → 出力
譜面の演奏・BGM用の素材 → BGM音量 → 原音・ディレイ・リバーブ ─┘
```

この構成では、全体を小さくする操作と、効果音を音楽より目立たせる操作を分けられます。
音量調整は次の三つの値で行います。

```js
synth.setMasterVolume(0.7); // 全体の出力倍率
synth.setSeVolume(0.90);     // 効果音の系統の倍率
synth.setBgmVolume(0.75);    // 背景音楽の系統の倍率
```

これらは`GameAudioSynth`の既定値です。
`0.40`は音量倍率として40%を意味し、体感上の大きさは音色、同時発音数、残響、出力機器にも左右されます。
最初は控えめなマスター音量から試し、SEとBGMのバランスを整えてから全体を調整すると聞き比べやすくなります。
`setBgmVolume()`で指定した倍率は、BGMを停止して再開するときにも使用されます。

### 旋律とリズムの音量を分ける

譜面形式のBGMでは、全体音量とは別にパートの倍率を設定できます。
旋律とリズムを聞き比べる場合は、次の二つを使います。

```js
synth.setBgmMelodyVolume(0.8); // 旋律だけを少し小さくする
synth.setBgmRhythmVolume(1.2); // ベース・和音・打楽器を強める
```

どちらも0〜2の倍率で、既定値は1です。
0にすると、そのパートの新しい音を予約しなくなります。
曲選択や停止・再開でも倍率を保持し、次に予約する音から変更を反映します。
すでに鳴っている音や、ディレイ・リバーブの余韻は自然に減衰します。
全体を小さくするときは`setBgmVolume()`を使います。

内蔵曲では、旋律の基準音量を控えめにし、キック、スネア、ハイハットで拍を支えています。
個別倍率は`GameAudioSynth`の`format: "score"`の演奏へ適用されます。
`AudioSynth`の度数形式の曲や、`playAudioBuffer()`でBGMバスへ送った録音素材には適用されません。
これらもBGMバス全体の音量とエフェクトは共有します。

## 出来事に効果音を付ける

効果音は、操作、衝突、獲得、成功などの出来事を短い音で伝えます。
画面の変化と同じタイミングで鳴らすと、利用者は操作の結果をつかみやすくなります。

```js
// コイン獲得が確定したときに呼ぶ
function onCoinCollected() {
  synth.playSe("coin");
}

// ダメージが確定したときに呼ぶ
function onPlayerDamaged() {
  synth.playSe("damage");
}
```

この例の関数は、音声の開始操作を済ませた後で呼び出します。
衝突の接触が数フレーム続く場合は、アプリケーション側で衝突開始や打撃の成立を一回の出来事として判断してから鳴らします。
これにより、出来事の回数と発音の回数を対応付けられます。

内蔵効果音には`paddle`、`wall`、`block`、`levelup`、`gameover`、`poyoon`、`piyoon`、`baan`、`shupa`、`coin`、`jump`、`laser`、`damage`、`powerup`、`ui_move`、`ui_ok`、`countdown`、`tail_probe`があります。

一覧は`getSoundEffectList()`、各音の情報は`getSoundEffectInfo(name)`で取得できます。
情報に含まれる`profiles`は、その音を構成する音量変化のプリセット名、`primaryProfile`は調整の起点となるプリセット名です。
`durationSec`は最後の層の発音とReleaseが終わるまでの秒数で、現在の包絡設定から計算します。
ディレイとリバーブの余韻はこの秒数に含みません。
例えば一つの効果音に、短い打撃音と長い余韻を重ねる構成があります。
UIを作るときは、この情報から編集対象を選べます。

### 打撃・動き・通知を音で書き分ける

内蔵18種類の効果音は、音程のある音と帯域を絞ったノイズを重ねて作ります。
連続する周波数変化はジャンプやレーザーの動き、フィルターの帯域変化は
破片や空気の流れ、低い胴鳴りは衝突や爆発を表すために使います。

- `paddle`と`wall`：短い打撃と低い胴鳴り。wallは低めで控えめな接触音。
- `block`：高めの短い破片ノイズと下降する音高。
- `baan`と`damage`：低い下降音とノイズ。baanは長めの爆発、damageは短い打撃。
- `shupa`：帯域が上下するノイズで、空気を切る動きを表す。
- `poyoon`、`piyoon`、`jump`：連続した上昇や下降で弾性と跳躍を表す。
- `laser`：高音から低音へ滑らかに下降する音と短いノイズ。
- `coin`、`levelup`、`powerup`：安定した音程、上昇するフレーズ、和音。
- `gameover`：下降するフレーズと低い終止音。
- `ui_move`と`ui_ok`：連打される操作を考慮した、小さく短い音。
- `countdown`：同音の短い反復に、開始を示す高い音を続ける。
- `tail_probe`：短いノイズと長い音を組み合わせた包絡・残響の確認音。

音程のある層とノイズの層は、どちらも既存のSEバスへ送ります。
SEの音量、ディレイ、リバーブ、左右の定位を同じ経路で扱えます。
各層の包絡は`profiles`に示される設定を使い、AttackとDecayが短い発音時間を
超える場合は同比率で短縮します。Releaseは現在のプロフィール設定を使います。
プリセット名は維持しているため、既存の`playSe(name)`をそのまま使えます。

発音ごとに作った音源、フィルター、音量、定位ノードは、発音終了時に切断します。
ノイズ素材は同じ乱数シードから再現できるよう生成して再利用し、BGMの打楽器とは
乱数の系列を分けています。場面を離れるときは`stopAllTones()`で、予約中の
ノイズと音程のある層をまとめて停止できます。BGMの譜面演奏は別管理です。

## 24曲のBGMを選ぶ

BGMは場面の雰囲気と時間の流れを作ります。
`GameAudioSynth`には、Jazzを中心とした12種類の曲調を各2曲ずつ用意しています。
各曲は4/4拍子の8小節で循環し、旋律、ベース、和音、打楽器を組み合わせて演奏します。

曲調ごとに2曲を示します。各項目は識別子、曲名、BPMの順です。

**Jazz swing**

- `jazz_corner` / Corner Quartet / 132

**Blues jazz**

- `jazz_blue_room` / Blue Room / 96

**Bossa jazz**

- `jazz_bossa` / Palm Terrace / 126
- `jazz_coast` / Coastal Breeze / 138

**Jazz ballad**

- `jazz_midnight` / Midnight Window / 72
- `jazz_velvet` / Velvet Rain / 78

**Modal jazz**

- `jazz_modal` / Dorian Walk / 118
- `jazz_quartal` / Quartal Horizon / 128

**Jazz funk**

- `jazz_sunset` / Sunset Pocket / 108
- `jazz_electric` / Electric Crosswalk / 120

**Jogging jazz**

- `run_swing` / River Run / 170
- `run_boardwalk` / Boardwalk Miles / 170

**Jogging synth**

- `run_neon` / Neon Stride / 175
- `run_midnight` / Midnight Circuit / 175

**Jogging pop**

- `run_sunrise` / Sunrise Sprint / 180
- `run_open_road` / Open Road / 180

- `music_nightfall` / Nightfall Chase / 156

初期選択は`jazz_cafe`、112 BPMです。
BPMは1分間の四分音符の拍数を表します。
ジョギング向けの6曲は、170、175、180 BPMの拍を感じながら聞き比べられます。
各曲の音色は波形合成で作り、曲調は和声、旋律、伴奏の配置、スウィングで表現しています。
旋律は音域だけでなく、反復、跳躍、発音位置、休符、音の長さを曲ごとに変えています。
例えばBlue RoomとEveningは低めの音域、Cafe StepsとDaylightは中音域を使います。
funkは短い反復と休符、バラードは長い音と呼吸、Quartal Horizonは四度の跳躍を中心に組み立てています。
同じ曲調の2曲でも、細かく刻む曲と長く歌う曲などの違いを聞き比べられます。

### 曲名を画面に表示する

プログラムの指定には識別子、画面表示にはラベルを使います。
`getMelodyList()`が識別子の配列、`getMelodyLabel(name)`が曲名・曲調・BPMを含む英語ラベルを返します。
`select`を曲の選択欄、`bpmOutput`を現在のBPMの表示要素として、次のように接続できます。

```js
for (const name of synth.getMelodyList()) {
  const option = document.createElement("option");
  option.value = name;
  option.textContent = synth.getMelodyLabel(name);
  select.appendChild(option);
}
select.value = synth.melodyName;
bpmOutput.textContent = String(synth.bpm);

// 曲の切り替えと、その曲の開始テンポの表示を同じ操作で行う
select.addEventListener("change", () => {
  synth.setMelody(select.value);
  bpmOutput.textContent = String(synth.bpm);
});
```

ラベルに含まれるBPMは曲に設定された開始テンポです。
演奏中にテンポを調整するUIでは、上の例のように現在値`synth.bpm`を別に表示すると、選択曲と現在の設定を確認できます。

### 場面に合わせてテンポと音高を設定する

`setMelody()`は曲を選び、その曲の開始テンポを適用して演奏位置を先頭へ戻します。
再生中なら予約済みの音を停止して新しい曲へ切り替えます。
場面固有のテンポを使う場合は、曲の選択に続けて`setBpm()`を呼びます。

```js
// 追跡場面の曲、テンポ、音高をまとめて選ぶ
function enterChaseScene() {
  synth.setMelody("music_pursuit");
  synth.setBpm(156);
  synth.setRootHz(220);
  synth.startBgm();
}
```

`setRootHz()`は旋律、ベース、和音の音高を同じ比率で変えます。
キック、スネア、ハイハットの音高や帯域は固定です。
既定値の220 Hzでは、譜面のMIDI音高に対応する周波数で演奏します。
440 Hzなら1オクターブ上、110 Hzなら1オクターブ下です。
半音上げる場合は`220 * 2 ** (1 / 12)`を指定します。
曲を切り替えるときもrootとBGMエンベロープは現在の設定を使うため、場面ごとに値を決める場合は一緒に設定すると管理しやすくなります。

## 8小節の譜面を登録する

作品固有の曲は、和音と旋律を数値で記述して追加できます。
`format: "score"`を指定した譜面では、`chords`の1行が1小節の和音、`lead`の1行が同じ小節の旋律です。
音高にはMIDIの番号を用い、60はC4、69はA4に対応します。
rootが220 Hzのとき、69は440 Hzで鳴ります。

次の例はC majorを中心とする8小節の曲です。
変数`synth`は、前節までで生成した`GameAudioSynth`を使います。

```js
synth.registerMelody("story_field", {
  format: "score",
  label: "Story Field — Gentle / 116 BPM",
  bpm: 116,
  swing: 0.5,
  groove: "basic",
  type: "triangle",
  leadGain: 0.034,
  leadGate: 0.84,
  chords: [
    [48, 52, 55], [53, 57, 60], [55, 59, 62], [48, 52, 55],
    [57, 60, 64], [53, 57, 60], [55, 59, 62], [48, 52, 55]
  ],
  lead: [
    [72, null, 76, null, 79, null, 76, null],
    [77, null, 76, 74,   72, null, 69, null],
    [71, null, 74, null, 79, null, 77, null],
    [76, null, 74, null, 72, null, -1, -1],
    [76, null, 81, null, 79, null, 76, null],
    [77, null, 76, null, 72, null, 69, null],
    [71, 74,   77, null, 79, null, 74, null],
    [76, null, 74, null, 72, null, -1, -1]
  ]
});

synth.setMelody("story_field");
```

音声の開始操作を済ませてから`synth.startBgm()`を呼ぶと演奏します。
同じ譜面を使った実行例が[16_03 独自BGM](examples/16_03.html)です。

### 譜面の各項目

`label`は画面表示用の文字列です。
`bpm`は曲選択時のテンポで70〜200、`swing`は1拍を二つの8分音符へ分ける比率で0.5〜0.67を指定します。
`0.5`なら等間隔、`0.62`なら前半を1拍の62%、後半を38%として配置します。
二つの時間の合計は1拍となり、指定したBPMを保ちます。

`chords`と`lead`はそれぞれ8行です。
和音の各行には3〜5個の整数音高を13〜115の範囲で置き、先頭を根音とします。
伴奏はこの根音を低音へ展開し、残りの音と組み合わせて和音を作ります。
`walk`では先頭から根音、第3音、第5音の順に置くと、低音進行を意図どおりに組み立てられます。

旋律の各行には、八分音符の位置を表す8個の要素を置きます。
各要素は0〜127の整数音高、`null`、`-1`のいずれかです。
整数は新しい音の発音、`null`は直前の音を延ばす位置、`-1`は明示的な休符です。
音価は次の発音、休符、小節末で区切ります。
小節の先頭に続く`null`は前小節の音を引き継がず、旋律の開始を遅らせます。
行全体が`null`または`-1`ならその小節の旋律を休みます。
旋律の休符中もベース、和音、打楽器は伴奏パターンに従って進みます。

```js
// C4を四分音符相当の間隔で鳴らし、1拍休み、E4を鳴らして再び休む
[60, null, -1, -1, 64, null, -1, -1]
```

`leadGate`は、次の発音・休符・小節末までの間隔に対する発音時間の比率で、0.1〜1を指定します。
小さい値では歯切れのよい音、大きい値では長く歌う音になります。
省略時は0.82です。内蔵曲では曲ごとに設定しています。

`leadGain`は旋律1音の基準音量で、0〜0.2を指定します。
実際の旋律音量は、この値にパート倍率、高音の補正、エンベロープ、BGMバスなどの倍率を掛けたものです。
省略時は`square`が0.032、ほかの波形は0.058です。
内蔵24曲では0.021〜0.036を明示して伴奏とのバランスを整えています。

`type`は旋律の波形です。
`sine`は丸い音、`triangle`は柔らかさと芯のある音、`square`は輪郭の強い音、`sawtooth`は倍音の豊かな音になります。
ベースは`triangle`、和音は`sine`で演奏します。
旋律には高域を抑えるローパスフィルターを通し、強い倍音の刺激を和らげています。
フィルターの遮断周波数は音高に応じた1400〜3000 Hz、共振を表すQは0.5です。
880 Hzを超える旋律では、実周波数に応じて音量を徐々に下げます。
`setRootHz()`で移調した後の周波数にも、この補正が適用されます。

`registerMelody()`はこれらの項目を検証し、和音と旋律の配列を複製して登録します。
設定の誤りは項目名を含む例外として確認できます。
曲データを編集して再登録した後は、`setMelody()`でその曲を選ぶと、冒頭から新しい設定を確認できます。

### 伴奏のリズムを選ぶ

`groove`はベース、和音、打楽器を鳴らす位置を選びます。
同じ和音でも、強拍を支える配置と裏拍を中心にした配置で、歩くようなリズムや跳ねるようなリズムを作れます。

| 値 | 伴奏の特徴 |
| :--- | :--- |
| `basic` | 1拍目と3拍目の低音、2拍目と4拍目の和音 |
| `walk` | 毎拍の低音と、裏拍を含む和音 |
| `bossa` | 拍の前後へ低音と和音を配置したリズム |
| `ballad` | 長めの和音で旋律を支える、ゆったりした配置 |
| `funk` | 裏拍を含む短い発音で拍の細かな動きを作る配置 |
| `run` | 毎拍の低音と裏拍の和音でテンポを示す配置 |

`walk`の4拍目の低音は、次の小節の根音の半音下から近づきます。
`basic`と`run`は和音の全構成音を使います。
ほかの伴奏では根音をベースへ分け、和音側は2番目以降の音を使います。
曲調の名前と伴奏パターンは組み合わせて選べます。
例えばModal jazzの内蔵曲は`bossa`の配置を使い、和音と旋律によって曲調を作っています。

### 打楽器で拍を支える

キックは周波数が下降する正弦波、スネアとハイハットは帯域を絞った短いノイズで作ります。
外部の音声ファイルを読み込まず、各音源をBGMバスへ接続します。
打楽器も旋律と同じBPMと`swing`で予約されるため、拍の時間関係をそろえられます。

- `basic`：1・3拍目のキック、2・4拍目のスネア、毎拍のハイハット。
- `walk`：1・3拍目のキック、2・4拍目のスネア、八分音符のハイハット。
- `bossa`：拍の前後にキックを置き、2・4拍目のスネアとハイハットを添える。
- `ballad`：1拍目のキック、4拍目のスネア、2・4拍目のハイハット。
- `funk`：裏拍にもキックを置き、2・4拍目のスネアと八分音符のハイハット。
- `run`：毎拍のキック、2・4拍目のスネア、八分音符のハイハット。

`walk`と`bossa`は標準の0.8倍、`ballad`は0.55倍の打楽器音量です。
`basic`で旋律が`sine`の曲は0.5倍にして、穏やかな旋律を支えます。
ハイハットの裏拍も弱め、拍の強弱を付けています。
`setBgmRhythmVolume()`で低音、和音、打楽器をまとめて調整できます。

打楽器は独立した短い音量包絡を使い、`setBgmEnvelope()`の影響を受けません。
BGMの音量、ディレイ、リバーブには追従するため、残響が強い設定では打音にも余韻が付きます。

## 音の立ち上がりと余韻

一つの音の聞こえ方は、波形と、発音中の音量変化で決まります。
この音量変化を「エンベロープ」と呼び、Attack、Decay、Sustain、Releaseの頭文字からADSRと表します。

Attackは音量がピークへ達するまでの時間、Decayはピークから持続音量へ移る時間、Sustainはピークに対する持続音量の比率、Releaseは音を終えるときの減衰時間です。
時間の単位は秒です。
BGMの既定値は次の設定です。

```js
synth.setBgmEnvelope({
  attack: 0.03,
  decay: 0.20,
  sustain: 0.60,
  release: 0.40
});
```

BGMの譜面演奏では、AttackとDecayの合計が音価に収まるよう、必要に応じて両方の時間を同じ比率で短くします。
Releaseには指定値と音価のうち短い時間を使います。
旋律ではさらに、次の発音・休符までに残された区切りの時間へReleaseを収めます。
ベースと和音は音価までのReleaseを使い、打楽器は専用の短い包絡で発音します。
この時間配分により、短い音符でも立ち上がり、減衰、持続、余韻の順で演奏します。
Releaseとバスの残響が加わるため、実際に聞こえる余韻は基本の音価より長くなることがあります。
BGMのSustainは0〜1、各時間は0以上で指定します。

`setBgmEnvelope()`は渡した項目を現在値へ組み合わせるため、`synth.setBgmEnvelope({ attack: 0.01 })`のように一項目ずつ調整できます。
SE側は音色のプリセットを単位として設定します。

```js
// 現在の音色設定を読み、立ち上がりだけを変更して登録する
const piano = synth.getSeEnvelopePreset("piano");
synth.setSeEnvelopePreset("piano", {
  ...piano,
  attack: 0.005
});
```

SEの設定は4項目をまとめて登録するため、部分的な変更には現在値を合成します。
`percussion`、`brass`、`woodwind`、`organ`、`piano`、`guitar`というプリセットがあり、音量の時間変化を選ぶために使います。
内蔵効果音では、音程のある層とノイズの層にこの包絡設定を使います。
`playGameTone()`でAttackなどを個別指定した場合は、その値がプリセットを上書きします。
`getSoundEffectInfo()`で使用するプリセットを確認しながら調整すると、変更した音の部分を追いやすくなります。

## ディレイとリバーブを調整する

ディレイは時間を置いて繰り返す音、リバーブは空間に広がる残響です。
SEとBGMにはそれぞれ独立した設定があり、操作音の輪郭を保ちつつ、音楽には広い響きを加えられます。

```js
// 反復間隔（秒）、繰り返し量、反復音の混合量
synth.setSeDelay(0.11, 0.26, 0.22);
synth.setBgmDelay(0.18, 0.22, 0.18);

// 残響へ送る量、出力へ戻す量
synth.setSeReverb(0.32, 0.55);
synth.setBgmReverb(0.28, 0.48);
```

ディレイの繰り返し量は、戻ってきた音を再びディレイへ送る倍率です。
1より小さい値から調整すると、反復が徐々に小さくなる響きを作れます。
時間は内部のDelayNodeが扱う0〜2秒の範囲で設定します。

リバーブの量は`setSeReverb()`と`setBgmReverb()`、響きの性質は次の設定で選びます。

```js
synth.setSeReverbImpulse({
  kind: "room",
  durationSec: 2.2,
  decay: 1.6
});
synth.setBgmReverbImpulse({
  kind: "hall",
  durationSec: 4.0,
  decay: 1.9
});
```

`kind`は`room`、`hall`、`plate`から選びます。
`durationSec`は残響データの長さ、`decay`は後半の減衰の仕方を表します。
同じ長さなら、decayを大きくすると後半が早く小さくなる方向へ変わります。

残響にはインパルスレスポンス（Impulse Response：短い入力に対する空間の応答）を使います。
webgは減衰するノイズと初期反射からステレオの残響データを生成し、ConvolverNodeで音へ適用します。
設定変更時にデータを生成するため、操作画面や場面切替のタイミングで更新する構成が適しています。
聞き比べには、短い音と長めの音を組み合わせた`tail_probe`が使えます。

## 単音を重ねて独自の効果音を作る

作品専用の音は、周波数、時間、音量を変えた単音を重ねて作れます。
`playGameTone(freq, dur, profile, options)`では、周波数をHz、持続時間を秒で指定し、音量変化のプリセットを選びます。

```js
// 音声開始後に呼び、三つの音を時間差で重ねて獲得音を作る
function playTreasureOpen() {
  const when = synth.ctx.currentTime;
  synth.playGameTone(523.25, 0.08, "guitar", {
    when, type: "triangle", gain: 0.07, pan: -0.08
  });
  synth.playGameTone(783.99, 0.12, "piano", {
    when: when + 0.04, type: "triangle", gain: 0.06, pan: 0.06
  });
  synth.playGameTone(1174.66, 0.16, "woodwind", {
    when: when + 0.09, type: "sine", gain: 0.04, pan: 0.20
  });
}
```

`when`は`AudioContext`上の秒単位の絶対時刻です。
最初に一度時刻を取得し、その時刻へ差を加えることで、音同士の時間関係をそろえます。
`pan`は左が-1、中央が0、右が1です。
`detune`を使うとセント単位で音高を調整でき、100セントが半音に相当します。

`ToneSynth`の`playTone()`を直接使う場合は、`options.profile`で音量変化のプリセットを指定します。
`playTone()`が返す再生ハンドルは、持続音の停止などを個別に管理したい場面で利用できます。

## 音声ファイルを再生する

声、環境音、録音した楽器などの素材は、名前付きの`AudioBuffer`として読み込みます。
`loadAudioBuffer(name, url)`が取得とデコードを行い、`playAudioBuffer(name, options)`が登録名から再生します。
`GameAudioSynth`からもこれらのメソッドを使えます。

次の例では、音声の開始操作を済ませてから一度素材を読み込み、ゲーム内の出来事に合わせて再生します。
URLには作品で用意した音声ファイルを指定します。

```js
await synth.loadAudioBuffer("door", "./audio/door.mp3");

// ドアを開いた出来事を、準備済みの素材で鳴らす
function playDoorSound() {
  return synth.playAudioBuffer("door", {
    bus: "se",
    gain: 0.8,
    pan: -0.15
  });
}
```

`bus: "se"`なら効果音、`bus: "bgm"`なら背景音楽の音量とエフェクトを通ります。
読み込み済みの素材は再利用でき、発音ごとに再生用ノードが作られます。
環境音をループさせる場合は、戻り値のハンドルを保持して終了時に止めます。

```js
await synth.loadAudioBuffer("forest", "./audio/forest_loop.ogg");
const voice = synth.playAudioBuffer("forest", {
  bus: "bgm",
  loop: true,
  gain: 0.45
});

// 場面を離れるときに、その環境音をフェードアウトする
voice.stop(synth.ctx.currentTime, { fadeSec: 0.4 });
```

`playbackRate`は再生速度、`detune`はセント単位の音高調整、`offset`は素材内の開始秒、`duration`は再生する素材の長さを秒で指定します。
素材の音高と再生速度は、これらの設定に応じて変化します。

取得済みのバイナリは`decodeAudioBuffer(name, arrayBuffer)`、作成済みの`AudioBuffer`は`registerAudioBuffer(name, buffer)`で登録できます。
一覧には`getAudioBufferList()`を使います。
読み込みや登録名の誤りは例外として受け取り、作品の状態表示へ伝えます。

BGMの譜面演奏と音声素材は、開始・停止の処理をそれぞれ持ちます。
譜面は`stopBgm()`、素材は`voice.stop()`または`stopAllAudioBuffers()`で停止します。
両方が同じBGMバスへ流れる構成では、`stopBgm()`によるバス音量のフェードも共有するため、場面を終える処理で両方の停止をまとめると管理しやすくなります。

## 音声の時刻に合わせて演奏する

BGMは少し先の時刻まで音符を予約して演奏します。
`GameAudioSynth`は既定で25ミリ秒ごとに予約処理を呼び、現在から0.20秒先までの音を`AudioContext`の時刻へ予約します。
各音の開始時刻は音声側で管理されるため、描画フレームの間隔が変わる場面でも音符の時間関係を保ちやすくなります。

`scheduleBgm()`が64個の八分音符位置を循環し、`scheduleScoreStep()`が各位置の演奏をまとめます。
`scheduleAccompaniment()`がベースと和音、`scheduleScoreDrums()`が打楽器を用意します。
`playScoreVoice()`が旋律・ベース・和音、`playScoreDrum()`が打音を予約します。
発音が終わった音源、音量ノード、フィルターは切断され、予約音の集合から取り除かれます。
曲切替や再開始ではノイズの音源も含めて予約済みの譜面音を止め、前の演奏を持ち越しません。

テンポ、音高、エンベロープ、パート音量の変更は、その後に予約する音へ反映されます。
この先読み時間を意識すると、スライダー操作から音が変わるまでの短い時間差を理解できます。
アプリケーションは場面の開始時に`startBgm()`、終了時に`stopBgm()`を呼び、演奏中の予約処理を音声クラスへ任せます。

## サンプルで聞き比べる

`samples/sound/sound.html`は、全体設定、効果音、BGMを一つの画面で調整するサンプルです。
Audio Startで音声を有効にし、Melodyで曲を選び、BGM Startで演奏を始めます。
選択時にその曲のBPMが表示され、続けてテンポ、音量、ADSR、ディレイ、リバーブを調整できます。
BGM Volは全体、Melody Volは旋律、Rhythm Volはベース・和音・打楽器の音量を調整します。
Melody Volを0にしてリズムだけを聞き、戻して旋律とのバランスを確認できます。
BGM ADSRの変更は旋律・ベース・和音に作用し、打楽器の短い包絡は保たれます。

効果音はPlay SEで一つずつ、Next SEで次の音へ進み、Audition Allで一覧を順に試聴できます。
Audition Allは各効果音の発音とReleaseに0.15秒の間隔を加え、長い達成音や終了音も最後まで演奏してから次へ進みます。
SEの編集対象は、その効果音が使用する音量変化のプリセットから選びます。
まず原音に近い設定で輪郭を聞き、その後リバーブの量と響きの種類を調整すると、音の長さと空間の余韻を分けて確認できます。
各設定を作品へ移すときは、曲の識別子と音響設定を場面ごとの関数やデータにまとめます。

## まとめ

音声の組み込みは、利用者の操作から`resume()`を呼び、音量を設定し、効果音とBGMを開始する流れで進めます。
`GameAudioSynth`の24曲は、8小節の旋律、ベース、和音、打楽器を曲調に合わせて演奏します。
独自の曲も同じ譜面形式で追加できます。

音量はマスター、SE、BGMに加え、譜面の旋律とリズムでも調整できます。
曲ごとの休符、発音時間、音域を組み合わせ、音色の時間変化はADSR、空間の響きはディレイとリバーブで整えます。
音声素材も同じ出力経路へ接続できるため、合成音と録音素材を組み合わせた作品を作れます。
