# Afterword

Thank you for reading this book.

This book aims to explain both how to display a scene with the `webg` API and how a 3D application is put together. It begins with coordinates and matrices, then moves through shaders, models, animation, input, UI, collision queries, physics, and screen effects. These capabilities work together inside an application, so understanding their relationships is as useful as learning each feature on its own.

When a model appears in the wrong place, an animation deforms unexpectedly, or input no longer matches what happens on screen, the next step is to find which stage introduced the problem. The ideas in these chapters can help you trace such issues one step at a time.

You can read the book from beginning to end or return to a chapter when a particular question arises. Check the feature's role in the text, try its usage in a runnable example, and inspect the core implementation when you need more detail. Starting with minimal rendering and application structure, then moving to cameras, physics, PBR, and internals as needed, gives each topic a practical context.

If you want to build something with `webg`, begin with a small subject: move one cube, or load a model and play an animation. Hands-on experiments connect the mechanisms in the book to your own experience.

I hope this book will be useful both when you take your first steps and when you pause to investigate a problem along the way.

Thank you.
