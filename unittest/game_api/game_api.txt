確認ページ: game_api

目的
- WebgApp、InputController、GameStateManager、collision helperを組み合わせ、状態遷移と入力・得点・HUDの対応を確認します。

準備条件
- playerとtargetはsphereのcollision shapeを持つ立方体です。
- play / pause / resultの3状態で、30秒のラウンドを進めます。

操作と期待結果
- ArrowLeft / ArrowRight / A / D、または左右のholdボタンでplayerを移動します。
- targetへの接触開始時に100点加算され、comboとtoastが更新されます。
- P / Esc / Pauseで一時停止します。停止中は位置・得点・残り時間が保持されます。
- Enter / Space / Start、またはP / Esc / Pauseでpauseから復帰します。停止直前の状態から進行を再開します。
- R / Resetは各状態から新しいラウンドを開始します。得点とcomboは0、残り時間は30秒、playerは左側へ戻ります。
- 得点300点または時間切れでresultへ進みます。Enter / Space / StartまたはR / Resetで次のラウンドを開始します。

使用するwebg機能
- WebgApp: 描画、入力、scene phase、HUD、toast
- InputController: action map、hold、pressed edge
- Shape.setCollisionShape、Space.addCollisionBody、Space.stepCollisions
- GameStateManager: アプリ側の状態管理

関連する利用例
- ゲーム全体の構成はsamples/breakoutやsamples/mazeを参照できます。
- このページでは停止・復帰と接触開始時の加点を、画面と数値表示で確認します。
